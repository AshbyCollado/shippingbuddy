# Shipping Buddy overview

Shipping Buddy is a local-first guided box-planning tool for adults who need to pack an item using a box or cardboard they already have. It should ask clear questions first, compare the protected item with available material, recommend feasible transformations, then present synchronized visual instructions and a physically coherent 3D preview.

## Target customer flow

1. Describe the item and choose a measured profile.
2. Choose a protection goal and optional clearance.
3. Select or measure an existing box/material source.
4. Compare protected-envelope requirements against the source.
5. Rank feasible construction methods by cuts, waste, complexity, and fit.
6. Review the chosen plan.
7. Follow paused, step-by-step infographic instructions synchronized with generated 3D geometry.
8. Replay, inspect, print, or export the completed plan.

## Supported milestone scope

- Item profiles: rectangular, cylinder/tube, rounded/ellipsoid, and measured L/U profiles.
- Sources: existing box as-is, saved box inventory, generic presets, transformed box, and advanced flat sheet.
- Transformations: height cut-down, quick horizontal shrink, precise flatten/re-score/rejoin, symmetric or unequal corner reform, true telescope, and a separately labeled splice prototype.
- Default surface units: inches with practical quarter-inch checkpoints; internal calculations remain millimetres.
- Local autosave and JSON backup/import. Accounts, licensing, and paid quotas are future work.

## Product boundaries

- Geometry fit is not a promise of retained compression strength or carrier approval.
- Structurally uncertain but geometrically valid plans may preview with a compact factual status.
- Common/existing boxes used as-is never show a false flat-sheet cutting workflow.
- The final folded model must use the same generated faces as the flat plan.
